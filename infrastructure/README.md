# Infraestrutura

Ambiente local: PostgreSQL e diretório de arquivos via adaptadores.

Destino previsto: Azure Database for PostgreSQL, Blob Storage e Key Vault, mantendo os contratos da aplicação sem dependência direta do provedor.

A implantação compatível com o estado atual, incluindo Azure Files e Azure Communication Services Email, está documentada em [azure/README.md](azure/README.md).
